# src/components/

React components for the Athanor desktop application UI.

## Files:
- `ActionPanel.tsx` - Main action panel component that coordinates prompt generation and file operations
- `ApiKeyManagementPane.tsx` - Dedicated component for secure API key management with provider selection
- `ApplicationSettingsPane.tsx` - Component for managing global application settings including experimental features
- `AthanorApp.tsx` - Root application component that coordinates file system lifecycle and layout
- `AthanorTabs.tsx` - Handles tab navigation UI and logic with conditional content rendering
- `CliPanel.tsx` - Implements a terminal interface using xterm.js, rooted in the project directory
- `CommandButton.tsx` - Button component for applying AI-generated changes from clipboard
- `FileContextMenu.tsx` - Context menu for file/folder operations, featuring "Expand all" and "Collapse all"
- `FileViewerPanel.tsx` - Displays file content with syntax highlighting
- `LinkifiedText.tsx` - A React component that parses a string for markdown-style links
- `MainLayout.tsx` - Main layout organizing file explorer, action panels, and logs
- `ProjectCreationDialog.tsx` - Handles initial project setup dialog when .athignore is missing
- `ProjectSettingsPane.tsx` - Component for managing project-specific settings
- `ReviewPanel.tsx` - Displays and manages file changes from AI output with diff visualization
- `SettingsPanel.tsx` - Enhanced settings panel with form inputs for both project and application settings

## Subdirectories:
- `action-panel/` - Subcomponents for the action panel functionality
- `fileExplorer/` - File explorer tree components and hooks
