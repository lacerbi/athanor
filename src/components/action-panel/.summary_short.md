# src/components/action-panel/

Specialized components supporting the ActionPanel functionality.

## Files:
- `CustomPromptsHelpModal.tsx` - Modal component providing help and guidance for creating custom prompt and task templates
- `PromptContextMenu.tsx` - Wrapper component around VariantsContextMenu to handle prompt-specific variant selection
- `SelectedFilesDisplay.tsx` - Displays selected file count with popover for managing, reordering, and removing files
- `SendViaApiControls.tsx` - Component for managing "Send via API" functionality including LLM preset selection
- `TaskContextMenu.tsx` - Wrapper component around VariantsContextMenu to handle task-specific variant selection
- `VariantsContextMenu.tsx` - Generic context menu component for displaying and selecting variants
