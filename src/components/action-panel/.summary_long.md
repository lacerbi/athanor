# src/components/action-panel/ - Detailed Analysis

## Overview
This subdirectory contains specialized React components that support the ActionPanel functionality. These components handle various aspects of the prompt generation workflow, including help modals, context menus, file selection display, and experimental API integration features.

## Component Details

### CustomPromptsHelpModal.tsx
A comprehensive help modal that guides users in creating custom prompt and task templates:
- **Tutorial Integration**: Links to GitHub documentation for detailed instructions
- **Folder Access**: Quick buttons to open project-specific and global prompts folders
- **AI Designer Tools**: Copy buttons for AI designer instructions (both prompt and task)
- **Visual Organization**: Well-structured sections with icons and clear explanations
- **Loading States**: Individual loading indicators for each action button
- **Error Handling**: Graceful handling of failed operations with appropriate logging

The modal provides three main sections:
1. Overview of custom template capabilities
2. Storage location guidance with folder access
3. AI-assisted design tools for template creation

### PromptContextMenu.tsx
A thin wrapper component that specializes the generic VariantsContextMenu for prompt-specific use:
- **Type Safety**: Uses PromptData type for proper typing
- **Logging Integration**: Adds logging when variants are selected
- **Event Handling**: Delegates variant selection to parent component
- **Clean Interface**: Simplifies parent component integration

### TaskContextMenu.tsx
Similar to PromptContextMenu but for task variants:
- **Task-Specific**: Uses TaskData type for task operations
- **Consistent Pattern**: Follows same structure as PromptContextMenu
- **Logging**: Records task variant selections for debugging
- **Reusability**: Leverages shared VariantsContextMenu component

### SelectedFilesDisplay.tsx
A sophisticated file selection management component with popover functionality:

**Main Features:**
- **File Count Badge**: Shows selected file count with visual indicator
- **Expandable Popover**: Click to reveal detailed file list
- **Drag-and-Drop Reordering**: Visual reordering with grip handles
- **Priority Numbers**: Visual priority indicators for file order
- **Smart Context Suggestions**: Shows AI-suggested relevant files
- **Quick Actions**: Add/remove files with single clicks

**Smart Context Integration:**
- Displays heuristically identified files (✨ icon)
- Shows neighboring files based on relevance scores (🔗 icon)
- Relevance score badges for transparency
- One-click promotion of suggested files to selection

**UI Polish:**
- Responsive popover positioning
- Click-outside to close behavior
- Smooth animations and transitions
- Clear visual hierarchy with sections

### SendViaApiControls.tsx
Experimental component for direct LLM API integration:

**Core Functionality:**
- **Model Selection**: Dropdown populated with available presets
- **API Key Filtering**: Only shows models with stored API keys
- **Request Management**: Send and cancel functionality
- **State Persistence**: Remembers last selected model
- **Error Handling**: Comprehensive error messages and logging

**Technical Implementation:**
- Async preset loading with loading states
- Request ID tracking for proper cancellation
- Response processing with command extraction
- Integration with ApplyAiOutputAction for results
- Environment variable support for API keys

**User Experience:**
- Contextual tooltips explaining the feature
- Dynamic button states (Send/Cancel)
- Disabled states with clear explanations
- Visual feedback during processing

### VariantsContextMenu.tsx
A reusable generic context menu component for variant selection:

**Core Features:**
- **Generic Design**: Works with any variant structure
- **Viewport Awareness**: Smart positioning to stay within bounds
- **Keyboard Navigation**: Full arrow key support
- **Active State**: Visual indicator for current selection
- **Accessibility**: Proper ARIA labels and roles

**Technical Details:**
- Dynamic position calculation on mount
- Click-outside detection for dismissal
- Escape key handling
- Focus management for keyboard users
- Configurable styling through constants
