# src/components/ - Detailed Analysis

## Overview
This directory contains all React components that make up the Athanor desktop application's user interface. The components are organized into a modular architecture with clear separation of concerns, ranging from high-level layout components to specialized UI panels and utility components.

## Component Architecture

### Core Application Components

**AthanorApp.tsx**
- Root component that initializes and coordinates the entire application
- Manages file system lifecycle through custom hooks
- Handles theme switching between light/dark/auto modes
- Tracks user activity for graph analysis triggers
- Manages project loading/switching and welcome screen display
- Sets up listener for graph analysis events

**MainLayout.tsx**
- Primary layout component organizing the main UI sections
- Left panel: File explorer with project info and action buttons
- Right panel: Content area with tabs and active panel display
- Bottom panel: Log viewer with resizable height
- Manages panel resizing through custom hooks
- Coordinates git diff viewing and file copying actions

**AthanorTabs.tsx**
- Tab navigation component with conditional rendering
- Supports: Prompt Studio, File Viewer, Review, Settings, CLI tabs
- Shows CLI tab only when terminal functionality is available
- Includes diff mode toggle for experimental features
- Integrates Apply AI Output button within tab bar

### Action Panel System

**ActionPanel.tsx**
- Central hub for AI prompt generation and task management
- Multi-tab support for parallel workspaces
- Dynamic prompt generation with customizable variants
- Task execution with file selection requirements
- Context field with intelligent suggestions
- Smart preview and file tree toggles
- Format type switching (XML/Markdown)
- Integration with custom prompt/task templates
- Experimental "Send via API" functionality

### File Management Components

**FileViewerPanel.tsx**
- Syntax-highlighted file content display
- Support for 20+ programming languages
- Line numbers and file metadata display
- Copy functionality (raw and formatted)
- Replace with clipboard feature
- Word wrap toggle with persistent settings
- Binary file detection and handling

**FileContextMenu.tsx**
- Right-click context menu for file/folder operations
- Recursive expand/collapse for folders
- Ignore functionality (.athignore integration)
- Pattern-based ignoring (single item vs all with name)
- Smart positioning within viewport

### Settings and Configuration

**SettingsPanel.tsx**
- Container organizing all settings components
- Two-column layout for project and application settings
- Includes API key management section

**ProjectSettingsPane.tsx**
- Project-specific configuration
- Project name override functionality
- Project info file selection with browse dialog
- AI summaries inclusion toggle
- .gitignore usage preference

**ApplicationSettingsPane.tsx**
- Global application settings
- UI theme selection (Light/Dark/Auto)
- Experimental features toggle
- Smart preview line range configuration
- File size threshold settings
- Smart context token limit
- Form validation and persistence

**ApiKeyManagementPane.tsx**
- Secure API key storage interface
- Provider selection based on available presets
- Key validation and format checking
- Environment variable fallback support
- Visual indicators for stored keys
- OS-level encryption with troubleshooting guidance

### Review and Apply Changes

**ReviewPanel.tsx**
- Comprehensive diff viewer for code changes
- Dual mode support: AI changes and Git diffs
- GitHub-style diff highlighting
- Intelligent diff block merging
- Navigation controls (file and diff level)
- Accept/reject functionality per change
- Warnings for files not in context
- Sticky header with action buttons
- Automatic scrolling to current change

**CommandButton.tsx**
- Monitors clipboard for AI-generated commands
- Validates command structure
- Triggers Apply AI Output action
- Dynamic tooltip based on clipboard content
- Disabled state management

### Specialized Components

**CliPanel.tsx**
- Integrated terminal emulator using xterm.js
- Persistent shell sessions per project
- Custom copy/paste handling
- Automatic resizing and focus management
- Session lifecycle management

**ProjectCreationDialog.tsx**
- Initial project setup wizard
- .athignore creation options
- .gitignore augmentation choice
- Dynamic text based on existing files

**LinkifiedText.tsx**
- Markdown link parser and renderer
- External URL handling through Electron
- Security-conscious link opening

## Key Features and Patterns

### State Management
- Extensive use of Zustand stores for global state
- Local component state for UI-specific concerns
- Custom hooks for complex state logic

### IPC Communication
- All file operations through window.electronBridge
- Type-safe method calls defined in global.d.ts
- Async/await patterns for main process operations

### UI/UX Considerations
- Tooltips throughout for user guidance
- Drag-and-drop support for file paths
- Keyboard navigation in menus and lists
- Dark mode support with theme persistence
- Responsive layouts with resizable panels

### Performance Optimizations
- React.memo and useMemo for expensive computations
- Debounced operations for user input
- Virtual scrolling considerations for large lists
- Lazy loading of syntax highlighter languages

### Security Features
- Secure API key storage with OS-level encryption
- External URL handling through approved channels
- Path validation for all file operations
- Sandboxed terminal sessions

## Dependencies and Integration

### External Libraries
- lucide-react for consistent iconography
- react-syntax-highlighter for code display
- xterm.js for terminal emulation
- diff library for change visualization

### Internal Dependencies
- Heavy reliance on stores/ for state management
- Utils for file operations and data transformation
- Services for complex business logic
- Actions for user-initiated operations

## Component Communication
- Props drilling minimized through store usage
- Event bubbling for nested component actions
- Ref forwarding for imperative operations
- Context menus with portal rendering
