# src/components/fileExplorer/ - Detailed Analysis

## Overview
This subdirectory implements a complete file tree explorer component with advanced features including multi-selection, drag-and-drop, context menus, and relevance visualization. The implementation follows React best practices with proper separation of concerns between presentation and logic.

## Component Architecture

### FileExplorer.tsx
The main container component that orchestrates the file tree display:

**Core Responsibilities:**
- Renders the top-level file tree structure
- Manages context menu lifecycle
- Delegates state management to custom hook
- Handles mouse leave events for UI cleanup

**Key Features:**
- Integration with FileContextMenu for right-click actions
- Recursive rendering through FileExplorerItem
- Clean separation between UI and business logic
- Proper ref forwarding for external control

**Props Interface:**
- `items`: Array of FileItem objects to display
- `level`: Nesting level (defaults to 0)
- `onViewFile`: Callback when file viewing is triggered
- `onRefresh`: Callback for refresh operations

### FileExplorerItem.tsx
The workhorse component that renders individual files and folders:

**Visual Features:**
- **Checkbox Selection**: Three-state checkboxes (unchecked, checked, indeterminate)
- **Relevance Visualization**: Background color intensity based on relevance scores
- **File Status Indicators**: Special icons for long files (scissors) and external resources
- **Current File Highlighting**: Bold blue text for currently viewed file
- **Drag-and-Drop**: Visual feedback during drag operations

**Smart Context Integration:**
- Displays AI-identified relevant files with gradient backgrounds
- Heuristic seed files get special highlighting
- Relevance scores influence visual prominence
- Threshold-based visualization to avoid noise

**Technical Implementation:**
- Recursive rendering for nested structures
- Optimized re-renders with proper React patterns
- Effect hooks for checkbox indeterminate state
- Dynamic styling based on multiple factors

**Interactive Features:**
- Click on name/icon to preview files
- Checkbox for selection management
- Drag handle for reordering
- Context menu on right-click
- Expand/collapse for folders

### hooks/useFileExplorer.ts
Custom hook encapsulating all file explorer logic:

**State Management:**
- `expandedFolders`: Set tracking which folders are open
- `contextMenu`: Current context menu state
- `currentDirectory`: Active project directory

**Core Functions:**
- `toggleFolder`: Expand/collapse folder state
- `handleExpandRecursively`: Open folder and all descendants
- `handleCollapseRecursively`: Close folder and all descendants
- `handleIgnoreItem`: Add items to .athignore
- `handleContextMenu`: Show context menu with position

**Side Effects:**
- Document click listener for context menu dismissal
- Current directory loading on mount
- Proper cleanup on unmount

**Recursive Operations:**
The hook implements sophisticated recursive operations:
```typescript
// Expand all descendants
const descendantIds = getAllDescendantFolderIds(item);
setExpandedFolders(prev => {
  const newSet = new Set(prev);
  newSet.add(item.id);
  descendantIds.forEach(id => newSet.add(id));
  return newSet;
});
```

## Advanced Features

### Relevance Scoring Visualization
The file explorer provides visual feedback for Athanor's relevance engine:

**Score Calculation:**
1. Files receive relevance scores from multiple sources
2. Scores are normalized to 0-1 range
3. Non-linear transformation applied for better visual distribution
4. Threshold filtering prevents low-relevance noise

**Visual Mapping:**
- Light mode: Blue background with varying opacity
- Dark mode: Blue background with adjusted opacity
- Context-selected files override relevance coloring
- Smooth gradients for professional appearance

### Multi-Selection Logic
Complex selection handling with proper parent-child relationships:

**Selection States:**
- Individual file selection
- Folder selection (selects all contents)

- Visual feedback through styling
