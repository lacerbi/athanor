# src/actions Directory Summary

Action handlers for UI operations including AI output processing, clipboard operations, and dynamic task prompt generation.

## Files

- **ApplyAiOutputAction.test.ts**: Comprehensive unit tests for ApplyAiOutputAction covering command parsing, execution scenarios, and clipboard operations.
- **ApplyAiOutputAction.ts**: Orchestrates command execution from AI content using dedicated command handlers for SELECT, TASK, and APPLY CHANGES operations.
- **ManualCopyAction.test.ts**: Unit tests for ManualCopyAction covering clipboard operations, file content formatting, and error handling scenarios.
- **ManualCopyAction.ts**: Handles manual copy operations to clipboard with content formatting, token counting, and path-aware code block formatting.
- **buildTaskAction.test.ts**: Unit tests for buildTaskAction covering prompt generation, state management, and error handling for task operations.
- **buildTaskAction.ts**: Generic task builder that generates dynamic prompts from task templates and integrates with workbench store.
- **descriptions.test.ts**: Unit tests for tooltip generation functions covering enabled/disabled states and various disable reasons.
- **descriptions.ts**: Provides tooltips and human-readable names for UI action buttons with state-based messaging.
- **index.ts**: Central export point for action handlers, types, and utility functions.
- **types.ts**: TypeScript type definitions for action states and common action parameters.
