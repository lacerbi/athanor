# Directory: src/stores

Purpose: Zustand state management stores handling all application state from file selections to settings.

## Files:

- `applyChangesStore.ts`: Manages file change operations from AI output including CREATE, UPDATE, and DELETE with validation and error handling.
- `cliStore.ts`: Maps project directories to terminal session IDs to maintain persistent CLI sessions across UI remounts.
- `commandStore.ts`: Manages clipboard content state and command validation with periodic updates.
- `contextStore.ts`: Manages intelligent context building by fetching and storing relevance-scored neighboring files based on selected files and task descriptions.
- `fileSystemStore.ts`: Manages file system state including file tree, preview settings, and prompt generation preferences.
- `logStore.ts`: Manages application logs with functionality to add and retrieve log messages with clickable entries.
- `promptStore.ts`: Manages prompt data using Zustand with array-based storage and active variant tracking with persistence.
- `settingsStore.ts`: Zustand store for managing both project and application settings state with loading states and errors.
- `taskStore.ts`: Manages task data using Zustand with array-based storage and active variant tracking with persistence.
- `workbenchStore.ts`: Manages workbench state including multi-tab task descriptions and outputs with per-tab file selections.
- `workbenchStore.test.ts`: Tests for workbench store including per-tab file selection logic and folder selection behavior.
