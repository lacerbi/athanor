## /home/luigi/athanor/src/commands

Command execution system for processing AI-generated XML commands including file operations, task management, and agent task creation.

### Files

- **agentTaskCommand.ts** - Command handler for creating agent tasks by writing content to .ath_materials directory with clipboard instruction support
- **applyChangesCommand.ts** - Processes apply changes commands by parsing XML content and preparing file operations with token counting
- **descriptions.ts** - Provides human-readable descriptions for command types used in tooltip display
- **index.ts** - Centralizes exports for all command-related functionality as a single entry point
- **selectCommand.ts** - Handles file selection based on provided paths with workbench store integration
- **taskCommand.ts** - Updates task description in workbench store based on command content
- **types.ts** - Centralizes command-related type definitions and constants for type safety

### Subdirectories

- **parser/** - XML parsing utilities for command block extraction and file operation processing
