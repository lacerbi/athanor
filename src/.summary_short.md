# Directory: src

Purpose: React-based UI layer implementing the renderer process with components, state management, and user interaction logic.

## Files:

- `App.tsx`: The minimal React application root that simply renders the main AthanorApp component.
- `index.tsx`: The entry point file that bootstraps the Athanor React application by mounting the root App component to the DOM.
- `index.css`: Global CSS styles with Tailwind configuration, custom animations, and theme-aware styling.

## Subdirectories:

- `actions/`: Action layer bridging UI interactions and business logic for tasks, copying, and AI command processing.
- `commands/`: XML-based command system enabling AI assistants to perform file operations and task management.
- `components/`: Complete UI component library including layouts, panels, file explorer, and settings management.
- `config/`: JSON configuration files for AI model presets with provider-specific settings.
- `hooks/`: Custom React hooks for dark mode, file drops, panel resizing, and file system lifecycle.
- `services/`: Core services managing files, templates, ignore patterns, and AI model configurations.
- `stores/`: Zustand state management for workbench, files, settings, context, and UI state.
- `types/`: TypeScript type definitions for global window APIs, model presets, prompts, and tasks.
- `utils/`: Foundation utilities for file processing, prompt building, documentation, and token counting.
