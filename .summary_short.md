# Athanor Root Directory - Short Summary

Athanor is an Electron-based AI workbench desktop app for integrating AI assistants into developer workflows through intelligent context building and change management.

## Key Files

- **README.md** - Main project documentation with installation, features, and quick start guide
- **package.json** - Node.js project configuration defining dependencies, scripts, and metadata (v0.7.10)
- **CHANGELOG.md** - Comprehensive version history tracking all changes from v0.1.0 to current v0.7.10
- **CONTRIBUTING.md** - Contributor guidelines covering development setup, standards, and DCO requirements
- **LICENSE** - Apache 2.0 open source license terms
- **PROJECT.md** - Technical architecture documentation detailing app structure, tech stack, and development guidelines
- **TUTORIAL.md** - User tutorial for getting started with Athanor's features and workflows
- **CLAUDE.md** - AI assistant instructions for Claude when working with this codebase
- **GEMINI.md** - AI assistant instructions for Gemini when working with this codebase
- **tsconfig.json** - TypeScript compiler configuration with strict typing and path aliases
- **jest.config.ts** - Jest testing framework configuration for unit tests
- **forge.config.js** - Electron Forge build configuration for packaging the desktop app
- **webpack.*.config.js** - Webpack bundler configurations for main, renderer, and preload processes
- **.eslintrc.js** - ESLint linter configuration (incompatible with ESLint 9+)
- **.prettierrc** - Prettier code formatter configuration
- **tailwind.config.js** - TailwindCSS styling framework configuration with dark mode support
- **postcss.config.js** - PostCSS configuration for CSS processing

## Directories

- **assets/** - Application icons and branding assets
- **common/** - Shared TypeScript types between main and renderer processes
- **docs/** - Additional documentation including troubleshooting and design specs
- **electron/** - Main process code including services, handlers, and workers
- **resources/** - Application resources including prompts, images, and default files
- **scripts/** - Build and development scripts
- **src/** - Renderer process React application code
- **tests/** - Test utilities and mocks
- **public/** - Static HTML template
- **out/** - Build output directory (gitignored)
- **node_modules/** - Dependencies (gitignored)
