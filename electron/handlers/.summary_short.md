# handlers/

IPC handler modules that bridge communication between the main and renderer processes, providing secure access to file system, Git, LLM, settings, and shell operations.

## Files

- **contextHandlers.ts**: Exposes RelevanceEngineService to renderer for calculating smart context based on task description and selected files
- **coreHandlers.test.ts**: Comprehensive unit tests for all 15 core IPC handlers with extensive mocking of Electron APIs
- **coreHandlers.ts**: Core IPC handlers for file system operations, path utilities, folder selection, and ignore rule management
- **fileOperationHandlers.ts**: File operation handlers for reading/writing files, directory traversal, and template path resolution
- **fileWatchHandlers.ts**: File watching handlers that set up directory watchers and forward change events to the renderer process
- **gitHandlers.ts**: Git operation handlers providing access to uncommitted changes and repository status through GitService
- **llmIpc.ts**: LLM integration handlers for getting providers/models and sending messages to AI services with API key checks
- **settingsHandlers.ts**: Settings management handlers for project and application settings persistence and retrieval
- **shellHandlers.ts**: Terminal emulation handlers for managing persistent shell sessions with PTY functionality
