# Directory: electron

Purpose: Main process implementation handling file operations, IPC communication, services, and native OS integration.

## Files:

- `main.ts`: Main electron process coordinating window management, file system operations, and IPC communication with lifecycle handling.
- `preload.ts`: Exposes protected methods for IPC communication and file system operations between main and renderer processes.
- `ipcHandlers.ts`: Sets up all IPC handlers by importing and initializing modular handler functions for unified communication.
- `windowManager.ts`: Handles Electron window creation, lifecycle management and error handling with environment-specific configuration.
- `ignoreRulesManager.ts`: Manages nested ignore rules by discovering and compiling .athignore/.gitignore files into a unified ruleset.
- `ignoreRulesManager.test.ts`: Comprehensive unit tests for the intelligent ignore file scanner and rule compilation system.

## Subdirectories:

- `handlers/`: IPC communication handlers bridging renderer requests to main process services.
- `services/`: Core business logic services for file operations, Git integration, project analysis, and AI features.
- `workers/`: Background worker threads for CPU-intensive tasks like project analysis.
- `__tests__/`: Test utilities and helpers for main process testing.
