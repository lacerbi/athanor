# /home/luigi/athanor/electron/services - Short Summary

This directory contains core services that power Athanor's file system operations, project analysis, and intelligent context discovery features.

## Files

- **DependencyResolver.test.ts** - Unit tests for the DependencyResolver service validating Python and JavaScript/TypeScript module resolution.
- **DependencyResolver.ts** - Resolves import/require specifiers to file paths with language-specific logic for Python and JavaScript/TypeScript.
- **DependencyScanner.test.ts** - Unit tests for DependencyScanner verifying dependency extraction across multiple languages.
- **DependencyScanner.ts** - Fast regex-based dependency scanner supporting JavaScript/TypeScript, Python, and CSS imports.
- **FileService.test.ts** - Unit tests for FileService covering path operations, file I/O, watchers, and ignore rules.
- **FileService.ts** - Central file system service managing all file operations, path normalization, watching, and ignore rules.
- **GitService.test.ts** - Unit tests for GitService covering repository operations and command output parsing.
- **GitService.ts** - Git integration service providing commit history, file tracking, and repository analysis capabilities.
- **PathUtils.test.ts** - Unit tests for PathUtils validating cross-platform path manipulation functions.
- **PathUtils.ts** - Stateless utilities for consistent cross-platform path manipulation with Unix-style normalization.
- **ProjectGraphService.ts** - Analyzes project structure to build dependency graphs, file mentions, and commit relationships for relevance scoring.
- **RelevanceEngineService.ts** - Two-phase scoring engine that identifies relevant context files using multiple heuristics and token budgeting (uses genai-lite/utils for prompt utilities).
- **SettingsService.ts** - Manages reading/writing of project and application settings JSON files with proper error handling.
- **ShellService.ts** - Manages persistent pseudo-terminal sessions for integrated CLI functionality with buffered output.
- **TaskAnalysisUtils.test.ts** - Unit tests for task analysis utilities validating keyword extraction and path mention detection.
- **TaskAnalysisUtils.ts** - Extracts keywords and identifies path mentions from task descriptions for relevance scoring.
- **UserActivityService.ts** - Tracks recently modified files in real-time by listening to FileService events.
- **wordFilters.ts** - Comprehensive stop-word lists and allowed short words for keyword filtering in task analysis.
