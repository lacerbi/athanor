# Directory: common/types

Purpose: TypeScript interfaces and types used by both main and renderer processes for IPC communication.

## Files:

- `file-service.ts`: Defines the core interface for all file system operations across the application, providing a unified API for path handling, file I/O, watching, and resource access.
- `git-service.ts`: Defines interfaces for Git repository operations including commit history, file status tracking, and diff analysis.
- `llm.ts`: Defines IPC channel constants and types for LLM (Language Model) operations enabling secure, type-safe communication between processes.
